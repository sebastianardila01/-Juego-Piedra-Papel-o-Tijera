# -Juego-Piedra-Papel-o-Tijera
✂️ Mini juego en PSeInt donde juegas Piedra, Papel o Tijera contra la máquina. Usa lógica condicional y números aleatorios. Perfecto para practicar estructuras básicas de programación de forma divertida y rápida.
Este es un mini juego clásico hecho en **PSeInt**, donde compites contra la máquina en una ronda de **Piedra, Papel o Tijera**. Ideal para practicar estructuras básicas de programación de forma divertida y rápida.

## 🎮 ¿Cómo jugar?

1. El programa te pide elegir:
   - 1️⃣ Piedra  
   - 2️⃣ Papel  
   - 3️⃣ Tijera  
2. La máquina elige al azar una opción.
3. Se comparan ambas elecciones y se muestra quién gana.

## 🧠 ¿Qué se aprende?

- Uso de condicionales (`Si`, `Sino`)
- Operadores lógicos (`Y`, `O`)
- Función `Aleatorio` para decisiones automáticas
- Lógica básica de juegos en programación

## 💻 Requisitos

- Tener [PSeInt](https://pseint.sourceforge.net/) instalado.
- Abrir y ejecutar el archivo `piedra_papel_tijera.pseint`.
